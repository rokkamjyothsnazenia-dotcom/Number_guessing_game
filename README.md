# Number Guessing Game 🎮

## About the Project
A simple console-based Number Guessing Game developed using Java.


The computer generates a random number between 1 and 100, and the player tries to guess it within five attempts.

## Features
- Random number generation
- User input using Scanner
- Higher and lower hints
- Maximum of five attempts
- Displays the result when the game ends

## Technologies Used
- Java
- JDK
- VS Code

## Concepts Practised
- Variables and data types
- Scanner and Random classes
- If-else statements
- While loops
- Break statement
- Counters

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open `Main.java`.
4. Run the program.
